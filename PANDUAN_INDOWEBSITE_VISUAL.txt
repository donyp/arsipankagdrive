🔑 ENVIRONMENT VARIABLES CHECKLIST
═════════════════════════════════════════════════════════════════════════════

Sebelum deploy, pastikan ini sudah diisi di backend/.env:

✓ SUPABASE_URL
  └─ Dari: Settings → API Keys (Project URL)

✓ SUPABASE_SERVICE_ROLE_KEY
  └─ Dari: Settings → API Keys (Service Role Key)

✓ JWT_SECRET
  └─ Generate dengan: node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

✓ SESSION_SECRET
  └─ Generate dengan: node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"

✓ PORT
  └─ Set ke: 8080

✓ NODE_ENV
  └─ Set ke: production

✓ ALLOWED_ORIGINS
  └─ Set ke: https://your-domain.com,https://www.your-domain.com


🚀 QUICK COMMANDS
═════════════════════════════════════════════════════════════════════════════

SSH ke Hosting:
  $ ssh username@your-hosting.com

Clone Aplikasi:
  $ cd ~
  $ git clone https://github.com/username/ARSIPHOST.git
  $ cd ARSIPHOST

Install Dependencies:
  $ npm install

Setup .env:
  $ cd backend
  $ cp .env.example .env
  $ nano .env
  (Edit dengan values dari Supabase)

Test Aplikasi:
  $ npm start
  (Harus ada: "Server running on port 8080")

Setup PM2:
  $ npm install -g pm2
  $ pm2 start ecosystem.config.js
  $ pm2 startup
  $ pm2 save

Monitor:
  $ pm2 status
  $ pm2 logs arsiphost
  $ pm2 monit
