📋 PRASYARAT:
  ✓ Sudah punya hosting Indowebsite

STEP 1: BUKA TERMINAL & SSH KE HOSTING
═════════════════════════════════════════════════════════════════════════════

Buka PowerShell / Terminal di komputer Anda:

Command:
────────────────────────────────────────────────────────────────────────────
ssh username@your-hosting-domain.com
────────────────────────────────────────────────────────────────────────────

Contoh:
────────────────────────────────────────────────────────────────────────────
ssh arsipdig@mail.arsipdig.com
────────────────────────────────────────────────────────────────────────────

Expected Output:
────────────────────────────────────────────────────────────────────────────
Last login: [date/time]
[username@hosting ~]$
────────────────────────────────────────────────────────────────────────────

Keterangan:
  - Ganti "username" dengan username hosting Anda
  - Ganti "your-hosting-domain.com" dengan domain hosting Anda
  - Enter password saat diminta
  - $ di akhir = berhasil SSH

🔧 TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

ERROR 1: "git command not found"
────────────────────────────────────────────────────────────────────────────
Solusi: Git tidak terinstall di hosting
  - Contact: support@indowebsite.com
  - Atau: Gunakan cPanel Application Manager untuk install Git


ERROR 2: "Permission denied (publickey,password)"
────────────────────────────────────────────────────────────────────────────
Solusi: SSH username/password salah
  - Check: Username & password dari Indowebsite
  - Verify: Anda connect ke correct hosting


ERROR 3: "npm: command not found"
────────────────────────────────────────────────────────────────────────────
Solusi: Node.js tidak terinstall
  - Contact: support@indowebsite.com
  - Atau: Gunakan cPanel Application Manager


ERROR 4: "fatal: repository not found"
────────────────────────────────────────────────────────────────────────────
Solusi: Repository URL salah atau repo private
  - Verify: URL benar: https://github.com/donyp/arsiphosting.git
  - Check: Repository adalah public
  - Atau: Gunakan GitHub token untuk private repo
