FILE REQUIREMENTS IN GOOGLE DRIVE
==================================================

Files must exist in Google Drive at this path structure:

/ARSIP ANKA/
├── zona-1/
│   ├── toko-balaraja/
│   │   ├── INVOICE/
│   │   ├── PPN/
│   │   └── NON/
│   └── [other tokos]/
├── zona-2/
│   └── [same structure]
└── [other zones 1-20]/
    └── [same structure]

The database stores storage_path like:
/ARSIP ANKA/zona-3a/toko-condet/NON/NON Condet 699.000 16 Mei.pdf

System will stream this exact path from Google Drive.

SECURITY & CREDENTIALS
==================================================

✅ Good security practices implemented:

1. Credentials stored in Railway environment only
   - Not committed to git
   - Protected by Railway security

2. rclone.conf generated at runtime
   - Temporary in-memory storage
   - Never exposed to git history

3. OAuth token auto-refreshes
   - Google handles refresh tokens
   - No manual token replacement needed

⚠️  Important:
   - Never share your OAuth credentials
   - Never commit rclone.conf to git
   - If credentials leaked, regenerate in Google Cloud Console

==================================================
TROUBLESHOOTING IF SOMETHING GOES WRONG
==================================================

Error 1: "didn't find section in config file"
→ Solution: Check all 3 env vars are added to Railway
→ Check values match exactly (copy from rclone.conf [drive1])

Error 2: Still showing demo PDF
→ Solution: Hard refresh (Ctrl+Shift+R)
→ Check Railway logs for [RcloneConfig] messages

Error 3: PDF loads but appears blank
→ Solution: File might not exist at that path in Google Drive
→ Verify database storage_path matches Google Drive path

Error 4: Permission denied
→ Solution: Google Drive OAuth scope insufficient
→ Regenerate OAuth with correct scopes
