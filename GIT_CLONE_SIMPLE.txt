⚡ QUICK STEPS (Hanya 7 baris command!)
═════════════════════════════════════════════════════════════════════════════

1️⃣ BUKA TERMINAL ANDA

   Windows:
   - Buka PowerShell atau Command Prompt
   
   Mac/Linux:
   - Buka Terminal


2️⃣ COPY-PASTE COMMAND INI SATU PER SATU
   (Tunggu setiap command selesai sebelum paste yang berikutnya)

────────────────────────────────────────────────────────────────────────────

ssh username@your-hosting-domain.com

   Ganti:
   - username = username hosting Anda (contoh: arsipdig)
   - your-hosting-domain.com = domain hosting Anda (contoh: mail.arsipdig.com)
   
   Contoh lengkap:
   ssh arsipdig@mail.arsipdig.com

────────────────────────────────────────────────────────────────────────────

cd ~

────────────────────────────────────────────────────────────────────────────

git clone https://github.com/donyp/arsiphosting.git

   ⏱️ Tunggu sampai selesai (2-10 menit)

────────────────────────────────────────────────────────────────────────────

cd arsiphosting

────────────────────────────────────────────────────────────────────────────

npm install

   ⏱️ Tunggu sampai selesai (2-5 menit)

────────────────────────────────────────────────────────────────────────────

ls -la

   Seharusnya lihat: backend, js, css, package.json, README.md, dll

────────────────────────────────────────────────────────────────────────────

git status

   Seharusnya lihat: "Your branch is up to date with 'origin/main'."

Q: Dimana saya dapat username & password hosting?
A: Email dari Indowebsite saat signup. Jika lupa bisa reset di control panel.

Q: Bagaimana jika ada error "git command not found"?
A: Git tidak terinstall. Contact support@indowebsite.com atau gunakan 
   cPanel Application Manager.

Q: Berapa lama proses clone?
A: Tergantung ukuran repo & internet speed (biasanya 2-10 menit).

Q: Boleh saya close terminal saat download?
A: JANGAN! Tunggu sampai "git clone" selesai (tidak ada error).

Q: Gimana jika terminal disconnect saat clone?
A: Ulangi dari langkah 1. Git akan lanjut dari mana terakhir.

Q: Folder mana yang ter-clone?
A: Di /home/username/arsiphosting/ (username Anda)
