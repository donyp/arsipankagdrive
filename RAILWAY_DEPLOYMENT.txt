📋 LANGKAH-LANGKAH DEPLOYMENT
═══════════════════════════════════════════════════════════════════

LANGKAH 1: Buka Railway
────────────────────────
1. Go to: https://railway.app
2. Login/Signup dengan GitHub
3. Klik "New Project" atau "Create"


LANGKAH 2: Connect Repository
──────────────────────────────
1. Pilih: "Deploy from GitHub"
2. Select repository: arsipankagdrive
3. Confirm authorization


LANGKAH 3: Add Environment Variables
──────────────────────────────────────

Di Railway dashboard, klik "Variables" dan tambahkan:

Variable 1:
  Key: SUPABASE_URL
  Value: https://xxx.supabase.co

Variable 2:
  Key: SUPABASE_SERVICE_ROLE_KEY
  Value: eyJhbGc... [dari Supabase]

Variable 3:
  Key: ENABLE_ALIST
  Value: false

Variable 4 (OPTIONAL):
  Key: NODE_ENV
  Value: production

Klik "Save" setelah semua var di-add.


LANGKAH 4: Configure Build
────────────────────────────
1. Railway auto-detect Node.js dari package.json
2. Build command: npm install (auto)
3. Start command: bash start.sh (auto-detect dari Dockerfile)


LANGKAH 5: Deploy
──────────────────
1. Railway otomatis mulai build saat push ke GitHub
2. ATAU: Klik "Deploy" button di dashboard
3. Tunggu build selesai (~3-5 menit)
4. Lihat logs untuk progress


LANGKAH 6: Get URL
───────────────────
Setelah deploy sukses:
1. Buka Railway dashboard
2. URL aplikasi: https://[project-name].railway.app
3. Atau: Klik "View" di dashboard

🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

PROBLEM: Build failed with "Alist download error"
SOLUTION:
  ✅ SUDAH FIX! Dockerfile updated untuk disable Alist
  - Push latest code ke GitHub
  - Click "Redeploy" di Railway
  - Build akan sukses

PROBLEM: "Cannot read SUPABASE_URL"
SOLUTION:
  - Verifikasi env vars di Railway dashboard
  - Var names harus EXACT (case-sensitive):
    SUPABASE_URL (bukan supabase_url)
    SUPABASE_SERVICE_ROLE_KEY
  - Redeploy setelah update vars

PROBLEM: Deployment timeout
SOLUTION:
  - Railway free tier build timeout normal
  - Tunggu sampai selesai
  - Atau upgrade untuk faster builds

PROBLEM: App crashes setelah deploy
SOLUTION:
  - Check logs di Railway dashboard
  - Verify env vars lengkap
  - Cek database connection
