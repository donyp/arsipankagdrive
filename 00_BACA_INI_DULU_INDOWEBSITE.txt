❓ FAQ SINGKAT
═══════════════════════════════════════════════════════════════════════════

Q: Database lama saya tidak akan tersentuh kan?
A: ✓ Benar. Kita pakai Supabase terpisah. Database lama aman.

Q: Berapa lama prosesnya?
A: ~60 menit dari awal sampai live.

Q: Apa yang perlu disiapin?
A: Hosting + Domain sudah ada, tinggal ikuti panduan.

Q: Gimana jika ada error?
A: Lihat TROUBLESHOOTING_INDOWEBSITE.md, sudah ada 10 common problems.

Q: Port 8080 itu apa?
A: Port tempat aplikasi Node.js berjalan. Public akan akses via domain.

Q: Kenapa pakai PM2?
A: Untuk auto-restart jika aplikasi crash atau server reboot.

Q: Apa itu .htaccess?
A: File untuk reverse proxy, mengalihkan traffic dari domain ke port 8080.

Q: Supabase itu bayar?
A: Ada free tier yang cukup untuk production kecil-medium.

Q: Bagaimana backup database?
A: Supabase auto-backup setiap hari. Manual backup juga bisa.

Q: Bisa upgrade database nanti?
A: ✓ Bisa, mudah di Supabase dashboard.
