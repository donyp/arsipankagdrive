RAILWAY SETUP (5 MINUTES)
==================================================

1. Go to Railway Dashboard
   URL: https://railway.app
   
2. Select your project: arsipankagdrive

3. Click "Variables" tab

4. ADD NEW VARIABLES:

Variable 1:
  Key: RCLONE_REMOTE
  Value: gdrive

Variable 2:
  Key: ENABLE_GDRIVE_SYNC
  Value: true

Variable 3 (IMPORTANT - Base path):
  Key: RCLONE_BASE_PATH
  Value: /ARSIP ANKA

Variable 4 (Rclone config file path):
  Key: RCLONE_CONFIG_PATH
  Value: /app/rclone.conf

5. UPLOAD rclone.conf to Railway

   Railway doesn't auto-upload files, so we need to:
   a) Deploy with rclone.conf (it's in repo now)
   b) Railway will pick it up during build
   
   OR if needed: Use Railway CLI to upload file
   
6. Click "Save" after adding all variables

7. Trigger REDEPLOY:
   - Go to Deployments tab
   - Click "Redeploy" button
   - Wait for build complete (~2-3 minutes)

TROUBLESHOOTING:

Problem: Still showing demo PDF
Solution:
  - Check Railway logs for errors
  - Verify RCLONE_REMOTE=gdrive variable is set
  - Make sure rclone.conf exists in repo root

Problem: 404 file not found
Solution:
  - File might not have storage_path in database
  - Check database files table: storage_path column

Problem: "didn't find section in config file" error
Solution:
  - rclone.conf not deployed
  - Re-push latest commit with rclone.conf
  - Wait for redeploy
