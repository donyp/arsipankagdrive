SECTION 2C: ENVIRONMENT SETUP
═════════════════════════════════════════════════════════════════════════
[ ] 1. Navigate to backend:
      [ ] cd backend
[ ] 2. Copy .env.example:
      [ ] cp .env.example .env
[ ] 3. Edit .env:
      [ ] nano .env
[ ] 4. Fill credentials:
      [ ] PORT=8080
      [ ] NODE_ENV=production
      [ ] SUPABASE_URL=<dari Phase 1>
      [ ] SUPABASE_SERVICE_ROLE_KEY=<dari Phase 1>
      [ ] ALLOWED_ORIGINS=https://your-domain.com,https://www.your-domain.com
[ ] 5. Generate JWT_SECRET:
      [ ] Run: node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
      [ ] Copy output → paste di JWT_SECRET=
[ ] 6. Generate SESSION_SECRET:
      [ ] Run: node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
      [ ] Copy output → paste di SESSION_SECRET=
[ ] 7. Save .env file:
      [ ] Ctrl+X → Y → Enter (di nano editor)
[ ] 8. Verify .env filled:
      [ ] cat .env | grep -E "SUPABASE|JWT|SESSION|PORT"
      [ ] Should show all values
