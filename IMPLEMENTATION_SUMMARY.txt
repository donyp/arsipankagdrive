================================================================================
                          HOW TO USE
================================================================================

FOR MODERATOR/SUPER_ADMIN:

1. Login to dashboard
   → See empty state with filter message

2. Select Year (e.g., 2026) and Month (e.g., September)
   → Dropdowns show selected values

3. Optionally add other filters (Status, Keterangan, Search)

4. Click "Terapkan Filter" button
   → Table populates with matching invoices
   → Year/Month dropdowns STAY filled
   → Filter state saved automatically

5. Click "Reset" to clear the table
   → Year/Month remain in dropdowns
   → Other filters cleared
   → Empty state shows again

6. Close tab and reopen dashboard
   → Year/Month automatically restore
   → Filter preferences remembered!

FOR ADMIN ZONA USER:

Same flow as moderator, but:
- Only sees invoices from their zone
- Different filter names (Supplier, Keterangan, etc.)
- Same year/month sticky behavior

================================================================================
                          TROUBLESHOOTING
================================================================================

PROBLEM: Empty state doesn't show
FIX: 
- Check browser console for errors
- Verify initInvoiceSystem() is called
- Clear localStorage and reload
- Check if showInvoiceEmptyState() function exists

PROBLEM: Filters don't persist after refresh
FIX:
- Check if localStorage is enabled
- Open DevTools → Application → LocalStorage
- Verify "invoiceFilterState" key exists
- Check for JSON parse errors in console

PROBLEM: Background scan shows error
FIX:
- This is normal (errors are silent by design)
- Check Network tab for API calls
- User can still manually filter
- No blocking happens to UI

PROBLEM: Admin zona filters don't work
FIX:
- Admin zona has separate JS implementation
- Check if zona filtering works in API
- Verify admin has proper authorization
- Check backend zona_id logic
